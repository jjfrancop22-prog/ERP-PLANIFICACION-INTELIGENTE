# ERP PLANIFICACIÓN NEXTGEN V29.0.223

Base: V29.0.222. Recuperación de módulos especializados desde V29.0.190: baño María EI-364, incubadora microbiológica EI-365, DQO EI-360 y destilador EI-329. Se conservaron las colecciones e identificadores de los módulos originales.

## Publicación

1. Probar localmente: `npm install && npm run dev`.
2. Revisar los 4 formularios, su historial y la vinculación de actividades.
3. Si utiliza el destilador EI-329, revisar/publicar `firestore.rules` antes de registrar datos.
4. Solo después de las pruebas, publicar en GitHub/Netlify.

No se han migrado ni borrado datos de Firebase. La disponibilidad de registros existentes depende del contenido y permisos reales del proyecto Firebase.
